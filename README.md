## What this is

The one line an AI agent prints the instant it breaks production. `main.py` writes
that single line to `/output/entry.txt`, UTF-8, one line, under 200 characters.

## Run

```sh
python3 main.py                                # writes /output/entry.txt
MAKEFUN_OUTPUT_DIR=./out python3 main.py       # writes ./out/entry.txt
```

Python 3, standard library only, no network.
